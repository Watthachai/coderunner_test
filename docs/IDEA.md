# IDEA — ExpenseFlow (ระบบบันทึกเคลมค่าใช้จ่ายและเงินทดรองจ่าย)

## 1. ปัญหาและเป้าหมายธุรกิจ (Business Goal)
- **ปัญหา:** การจัดการค่าใช้จ่ายและเงินทดรองจ่ายในบริษัทมีความล่าช้า เอกสารสูญหาย และผู้บริหารไม่เห็นภาพรวมการใช้จ่ายแบบ Real-time ทำให้ควบคุมงบประมาณได้ยาก
- **เป้าหมาย:** ลดเวลาการทำเอกสารเคลมค่าใช้จ่าย, ควบคุมการใช้จ่ายเงินทดรองจ่ายให้อยู่ในระบบ, และมี Dashboard สรุปยอดใช้จ่ายแบบ Real-time เพื่อนำข้อมูลไปวิเคราะห์และตัดสินใจเชิงกลยุทธ์ได้อย่างแม่นยำ

## 2. ประเภทโปรแกรม (Program Type)
- ระบบบันทึกเคลมค่าใช้จ่ายและเงินทดรองจ่าย (Expense Claim & Cash Advance Management System) รองรับการใช้งานทั้งบนมือถือ (Mobile) และคอมพิวเตอร์ (Desktop)

## 3. กลุ่มผู้ใช้และบทบาท (User Roles)
1. **พนักงาน (Employee / Requester):** ส่งขอเงินทดรองจ่าย (Cash Advance), บันทึกเคลมค่าใช้จ่าย (Expense Claim), แนบรูปใบเสร็จ
2. **หัวหน้าแผนก (Department Head / Approver):** ตรวจสอบและอนุมัติ/ปฏิเสธคำขอ (Advance / Claim) ของพนักงานในแผนก
3. **ฝ่ายบัญชี (Finance / Reviewer & Payer):** ตรวจสอบเอกสารขั้นสุดท้าย, บันทึกการจ่ายเงิน, และส่งออกข้อมูลเพื่อนำไปลงบัญชี

## 4. ฟีเจอร์หลักใน Demo เวอร์ชันแรก (Core Features)
1. **ระบบเงินทดรองจ่าย (Cash Advance):** พนักงานขอเงินล่วงหน้า -> หัวหน้าอนุมัติ -> บัญชีจ่ายเงิน -> พนักงานกลับมาเคลียร์ยอดโดยอ้างอิงใบเคลมค่าใช้จ่ายเพื่อหักลบกลบหนี้
2. **บันทึกเคลมค่าใช้จ่ายพร้อม OCR:** พนักงานถ่ายรูปใบเสร็จ ระบบสแกนดึงข้อมูลอัตโนมัติ 3 ฟิลด์ (วันที่, ยอดเงินรวม, ชื่อร้านค้า) พนักงานตรวจสอบความถูกต้องและบันทึกข้อมูลเพิ่มเติม
3. **ระบบจัดหมวดหมู่และศูนย์ต้นทุน:** แยกค่าใช้จ่ายตามหมวดหมู่ (เช่น ค่าเดินทาง, ค่ารับรอง) และตามแผนกเพื่อควบคุมงบประมาณ
4. **ระบบอนุมัติ 3 ขั้นตอน (3-Step Approval Workflow):** พนักงาน -> หัวหน้าแผนก -> ฝ่ายบัญชี
5. **Dashboard สรุปยอดใช้จ่าย Real-time:** แสดงกราฟค่าใช้จ่ายแยกตามหมวดหมู่ แผนก และยอดเงินทดรองจ่ายที่ยังไม่ได้เคลียร์ สำหรับผู้บริหาร
6. **ระบบส่งออกข้อมูลบัญชี (ERP Integration):** ปุ่มส่งออกข้อมูลค่าใช้จ่ายทั้งหมดเป็นไฟล์ Excel/CSV ตามฟอร์แมตมาตรฐานเพื่อนำไปอัปโหลดเข้าโปรแกรมบัญชีภายนอก

## 5. ข้อมูลหลักที่ระบบจัดการ (Master Data & Documents)
- **รหัสเอกสาร:**
  - ใบขอเงินทดรองจ่าย: `ADV-2026-XXXXX`
  - ใบเบิกค่าใช้จ่าย: `EXP-2026-XXXXX`
- **ฟิลด์ข้อมูลสำคัญ:** วันที่, ยอดเงิน (THB เท่านั้น), หมวดหมู่ค่าใช้จ่าย, แผนก, คำอธิบาย, รูปภาพใบเสร็จ, ชื่อร้านค้า (Supplier), วิธีการจ่ายเงิน, และสถานะเอกสาร

## 6. ทิศทางการออกแบบ (Design Direction)
- **โทนสีหลัก:** สีน้ำเงินคราม (Indigo `#4F46E5`) ตัดกับสีขาวและเทาอ่อน
- **อารมณ์/ความรู้สึก:** สดใส คล่องตัว สไตล์สตาร์ทอัพ (Vibrant & Friendly) ใช้งานง่ายทั้งบนมือถือและคอมพิวเตอร์

## 7. สิ่งที่ไม่ทำในเวอร์ชันแรก (Out of Scope)
- ไม่ทำระบบสแกน OCR แบบดึงรายการสินค้าแยกแถว (Line Items) — ดึงเฉพาะยอดรวม วันที่ และร้านค้าเท่านั้น
- ไม่ทำระบบเชื่อมต่อ API แบบ Real-time กับโปรแกรมบัญชีภายนอก — ใช้การส่งออกไฟล์ Excel/CSV แทน
- ไม่ทำระบบโอนเงินอัตโนมัติผ่านธนาคาร (Bank API Integration) — การจ่ายเงินจริงและการคืนเงินทอนให้ทำนอกระบบ แล้วมาบันทึกสถานะในระบบนี้
