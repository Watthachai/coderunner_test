# สรุปไอเดียโปรเจกต์: Cafe Pre-order & Pick-up System

## 1. เป้าหมายและประเภทระบบ
- **ประเภทระบบ:** ระบบสั่งเครื่องดื่มล่วงหน้าและรับสินค้าที่ร้าน (Web Application รองรับ Mobile-First สำหรับลูกค้า และ Desktop/Tablet สำหรับพนักงาน)
- **เป้าหมาย:** ลดเวลาต่อคิวของลูกค้าหน้าร้าน เพิ่มความสะดวกรวดเร็ว และช่วยให้พนักงานจัดการคิวออเดอร์ได้อย่างเป็นระบบ

## 2. กลุ่มผู้ใช้งานหลัก
- **ลูกค้า (Customer):** สั่งเครื่องดื่ม ปรับแต่งเมนู ชำระเงิน และติดตามสถานะผ่านมือถือตัวเอง
- **พนักงานร้าน (Staff):** ตรวจสอบออเดอร์ ยืนยันการชำระเงิน และอัปเดตสถานะการชงเครื่องดื่ม

## 3. ขอบเขตฟีเจอร์เวอร์ชันแรก (V1)
### ฝั่งลูกค้า (Customer Flow):
- เลือกเมนูเครื่องดื่ม และปรับแต่งได้ละเอียด:
  - ระดับความหวาน (0%, 25%, 50%, 100%)
  - ประเภท (ร้อน / เย็น / ปั่น)
  - ท็อปปิ้ง/ตัวเลือกเสริม (เพิ่มช็อตกาแฟ, ไข่มุก, เจลลี่)
  - ประเภทนม (นมจืด, นมถั่วเหลือง, นมโอ๊ต)
- ระบบตะกร้าสินค้า คำนวณราคาสินค้า ค่าท็อปปิ้ง และส่วนลดสมาชิกอัตโนมัติ
- ระบบชำระเงินแบบสแกน QR Code และอัปโหลดรูปภาพสลิปเพื่อยืนยัน
- หน้าจอติดตามสถานะออเดอร์แบบเรียลไทม์ (รอคิว / กำลังทำ / รับได้แล้ว)
- ระบบสมาชิกสะสมแต้มและส่วนลด

### ฝั่งพนักงาน (Staff Flow):
- หน้าจอ Dashboard รับออเดอร์เรียลไทม์
- ตรวจสอบสลิปชำระเงินและกดยืนยันออเดอร์
- ปุ่มเปลี่ยนสถานะออเดอร์ (กำลังทำ -> เสร็จแล้ว/พร้อมรับ)

## 4. ทิศทางการออกแบบ (Design Direction)
- **โทน/อารมณ์:** สดใส น่ารัก สไตล์คาเฟ่เกาหลี (Minimalist & Pastel)
- **สีหลัก (Primary Color):** สีชมพูพาสเทล (Pastel Pink #FFD1DC) และสีครีมละมุน

## 5. สิ่งที่ไม่ทำใน V1 (Out of Scope)
- ระบบตัดบัตรเครดิต/เดบิตอัตโนมัติ (ใช้การแนบสลิปโอนเงินเท่านั้น)

## 6. เกณฑ์การยอมรับ (Success Criteria)
- ลูกค้าสามารถสั่งซื้อ ปรับแต่งเมนู แนบสลิป และติดตามสถานะแบบเรียลไทม์ได้จริง
- พนักงานสามารถรับออเดอร์และเปลี่ยนสถานะจนเสร็จสิ้นกระบวนการได้
- ระบบคำนวณราคาสินค้า ค่าท็อปปิ้ง และส่วนลดสมาชิกได้อย่างถูกต้อง 100%
